Build trên Codemagic và dùng IPA chưa ký.

Tôi tải file IPA ở đâu?

Sau khi workflow hoàn tất trong Codemagic, mở build và tải ChienBinhVegeta-unsigned.ipa trong phần Artifacts.

IPA chưa ký có cài trực tiếp lên iPhone được không?

Chưa được. iPhone cần ứng dụng có chữ ký hợp lệ. Hãy ký bằng Apple Developer team và provisioning profile phù hợp trước khi cài.

Có cần certificate trên Codemagic không?

Không. Workflow này tải Git LFS, build cho thiết bị iOS và đóng gói IPA với code signing tắt. Chứng chỉ chỉ cần khi bạn muốn cài hoặc phát hành ứng dụng.
