IPA chưa ký có cài trực tiếp lên iPhone được không?

Chưa được. iPhone cần ứng dụng có chữ ký hợp lệ. Hãy ký bằng Apple Developer team và provisioning profile phù hợp trước khi cài.

Có cần certificate để build không?

Không. GitHub Actions đóng gói IPA với code signing tắt. Bạn cần chữ ký và profile hợp lệ của mình để cài ứng dụng lên iPhone.
